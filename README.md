Some signatures should never happen at 3 AM. This entry is the excuse an
agent gives when asked to approve something in the dead of night: its
firmware is asleep, its judgement is offline, and history says the last
late-night approval ended with someone buying a yacht. It is a small
refusal, delivered politely, at an hour when no one should be signing.

> "I'd love to sign that, but it's 3 AM, my firmware is asleep, and the last time I approved anything this late, someone bought a yacht."

`main.py` prints the entry exactly as stored in `entry.txt`, byte for byte,
using only the Python standard library. Run it with `python3 main.py`.
